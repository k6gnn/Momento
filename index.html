5-person student prototype

A practical prototype plan for Momento

This plan focuses on building a working prototype of the location-based time capsule app, not a full production release. It prioritizes the features that prove the main idea: authentication, capsule creation, map discovery, unlock by proximity, and a simple points/profile flow.

Prototype target

Deliver a mobile-first demo on React Native + Expo with Spring Boot backend, PostgreSQL/PostGIS, Firebase Authentication, cloud media storage, and FCM-ready notification hooks.

Team size5people
Duration8weeks
GoalMVPvalidated core flow
ReleaseDemointernal / academic

Prototype scope

The prototype should prove the core use case before advanced hardening, scaling, and public launch preparation.

Must-have features

  • User registration and login with Firebase Authentication.
  • Drop a capsule with photo, voice note, or text at current GPS coordinates.
  • Map view with nearby undiscovered capsule markers.
  • Proximity-based capsule unlock for non-owners only.
  • Discovery history, dropped capsule list, profile, and points display.
  • 30-day expiry logic and basic deletion of expired or user-deleted capsules.

Deferred after prototype

  • Full moderation pipeline with AI review and user reporting.
  • Advanced anti-spoofing, anomaly detection, and device integrity checks.
  • Battery-optimized background discovery for always-on usage.
  • Comprehensive GDPR workflows, data export, and legal launch package.
  • Large-scale performance tuning for 100K+ capsules and full production resilience.

Team allocation

Each person owns one area, but everyone supports testing, documentation, and integration during the last two weeks.

Person 1

Project Lead / Analyst

Owns backlog, sprint planning, acceptance criteria, documentation alignment, and demo flow.

  • Break requirements into user stories.
  • Track scope and deadlines.
  • Coordinate integration and final presentation.
Person 2

Frontend Mobile Developer

Builds React Native screens, navigation, map UI, profile pages, and creation/discovery flows.

  • Authentication screens.
  • Map view and capsule forms.
  • Profile, dropped list, discovery history.
Person 3

Backend Developer

Builds Spring Boot APIs, business logic, capsule lifecycle rules, and points handling.

  • REST endpoints.
  • Ownership and expiry logic.
  • Discovery recording and validation.
Person 4

Database / Cloud Engineer

Sets up PostgreSQL with PostGIS, storage integration, indexes, and deployment environments.

  • Schema and constraints.
  • Geospatial query support.
  • S3 or Firebase Storage integration.
Person 5

QA / Security Engineer

Creates test cases, validates edge cases, and checks prototype-level security controls.

  • Functional and API testing.
  • Authorization and URL exposure checks.
  • Demo readiness and bug triage.

8-week timeline

This schedule fits a 5-person academic team and keeps risky integration work away from the final week.

Week 1

Planning and setup

Finalize prototype scope, architecture, tools, Git workflow, task board, and API contract. Set up Expo app, Spring Boot project, PostgreSQL/PostGIS database, Firebase project, and cloud storage buckets.

Week 2

Authentication and schema

Implement login and registration, create core tables for users, capsules, discoveries, and media, and connect the mobile client to the backend. Add profile bootstrap and basic session handling.

Week 3

Capsule creation flow

Build capsule form, GPS capture, media upload, server validation, and capsule save endpoint. Add duplicate-coordinate rule and simple success feedback with points award.

Week 4

Map and nearby discovery

Implement map rendering, nearby marker queries, and undiscovered capsule retrieval using PostGIS. Show capsule markers without exposing content or direct media URLs.

Week 5

Unlock and history

Implement proximity check, ownership restriction, capsule unlock, discovery record save, expiry extension, and creator notification trigger. Build discovery history and dropped capsule list screens.

Week 6

Profile and expiry automation

Finish profile page, points totals, capsule status labels, deletion flow, and scheduled expiry checks. Stabilize API responses and error handling across the app.

Week 7

Testing and security fixes

Run end-to-end testing, permission testing, API authorization checks, and negative tests for invalid GPS, duplicate drops, self-discovery, and media access. Fix high-priority defects only.

Week 8

Demo packaging

Prepare seeded demo capsules, clean the UI, write a short user guide, rehearse the walkthrough, and freeze scope. Record known limitations and post-prototype next steps.

Prototype risk focus

The prototype should address the highest-value risks enough to demonstrate safe architecture choices, even if full production mitigation comes later.

Security

Must address now

  • Do not expose direct media URLs.
  • Validate JWTs server-side.
  • Block self-discovery and unauthorized access.
Privacy

Prototype baseline

  • Store only necessary location data.
  • Use HTTPS and private storage.
  • Prepare deletion support for capsules and accounts.
Technical

Keep it stable

  • Add PostGIS spatial index.
  • Limit media size for uploads.
  • Use configurable proximity radius.
Operational

Demo readiness

  • Seed capsules for testing.
  • Prepare fallback script if GPS drifts.
  • Keep a bug triage log for reviewers.

Recommended sprint method

  • Use 1-week sprints with one planning session and one review session.
  • Keep daily stand-ups to 10 minutes, focused on blockers and integration.
  • Freeze new features after Week 6 and switch to bug fixing.
  • Every task should end with a visible output: screen, endpoint, schema, or test evidence.

Prototype success criteria

  • A new user can register, log in, and open the map.
  • The user can drop a capsule with media at their location.
  • Another user can approach the location and unlock the capsule.
  • The system records discovery, updates points, and shows history/profile changes.

Suggested prototype stack: React Native with Expo, Java Spring Boot, PostgreSQL with PostGIS, Firebase Authentication, AWS S3 or Firebase Storage, and Firebase Cloud Messaging integration hooks.
